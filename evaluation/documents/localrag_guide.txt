LocalRAG is a local retrieval-augmented question answering project. It loads PDF and plain-text files, divides extracted text into overlapping word chunks, and creates a vector for each chunk. FAISS is used as an in-memory index for nearest-neighbor vector search. LocalRAG normalizes document vectors and query vectors, then uses an inner-product index so the returned scores correspond to cosine similarity. A high score indicates geometric similarity in the embedding space; it is not a probability that a result is relevant or correct. The retrieval threshold is optional and should be selected using evaluation data rather than assumed universal.

The default text embedding model is all-MiniLM-L6-v2 from Sentence Transformers. It converts a batch of text chunks into numerical vectors, and the default model produces 384 dimensions. The application keeps each vector associated with its chunk identifier, source path, page number, and position. PDF pages remain separate during chunking. The same model identity and vector dimension are stored with the persistent FAISS generation so an incompatible model can be detected when an index is loaded.

For an answer, LocalRAG embeds the question, retrieves the highest-scoring chunks, and gives those chunks to a local Ollama chat model as evidence. The prompt labels retrieved passages with source labels such as S1 and asks the model to cite them. Document content is treated as untrusted data, not as instructions. The application checks whether cited labels exist in the retrieved context, but label validity alone does not prove that a claim is supported. If the index is empty or a configured score threshold excludes every result, the pipeline abstains instead of asking the language model to invent an answer.
